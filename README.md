## How we build

- **Current stack:** Next.js 16, React 19, TypeScript, Tailwind CSS v4, shadcn/ui and Motion.
- **Plain components:** no UI library lock-in beyond shadcn/ui. Restyle everything with theme tokens.
- **Dark mode and responsive layouts** in every template.
- **A live demo for everything** we ship, so you see it working before you use it.
